# 灰度轨

中文名：**灰度轨** · 前缀 `flagrail` · 端口 **6800 / 11800**

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

领域：**基础设施** · 子方向：**中间件**

## 名单百分比互斥（已落地）

同一开关键下，百分比规与名单规**不得并行生效**。全局策略键 `名单百分比互斥策略`（站规表）只有一个合法取值：

- `名单归档百分比` —— **乙口径**：名单写入成功 → 同键原百分比规归档失效（`归档因=名单接管`），生效集只留名单规；百分比回写**整拒**（须先 `/api/分桶/归档` 人工归档名单）。
- 甲口径（后写类型冲突整拒、已有百分比生效时名单写入失败）**不提供**；若站规被改成其它值，核证 `valid=false` 且**停写**（失败闭），不让两套口径并行。

核对点：两次写入（百分比 → 名单）后生效集**不含**百分比（乙）；甲则会含。`互斥核证` 的逐键 `口径结局` 直接给出 `甲:含百分比` / `乙:不含百分比`，两口径结局可区分。

硬约束落实：

| 约束 | 实现 |
| --- | --- |
| 分桶写入与下发读规同票 | 下发在写事务内读规并落票，票面烙 `桶类型 / 规世代 / 规更新时` 快照 |
| 半截不得双规生效 | 写规的「归档旧规 + 落新规」在同一 `BEGIN IMMEDIATE` 事务内 |
| 写规与下发并发须失败闭 | 写事务零等待；拿不到写锁立即 409，绝不排队后按旧规落半截 |
| 下发选归档规必须失败 | `/api/下发` 对 `状态=已归档` 返回 409，票不落、版本态不动 |
| 不得只在 UI 藏一种桶类型 | 分桶规页列出归档规（带归档因/归档时）；写入口不做类型白名单隐藏 |

核证与协同：

- `GET /api/互斥核证?开关键=…`（留空=全站）：开关键、生效规列表、归档规、策略标记、`valid`；逐键含 `口径结局`、`票据`（挂着已归档规的票标 `需复核`）。
- `GET /api/分桶规`：生效规在前，归档规随后列出，不隐藏。
- **回读协同**：票面规世代与库中生效规不一致（被归档/被同类型替换）→ 确认回读转「偏差 · 规漂移」。
- **轨贯验**：同键生效互斥族规至多一条、无双类型并行、已下发票不得落在归档规上。

夹具与自动化：

```bash
python3 backend/scripts/核证_名单百分比互斥.py   # 双序写入 + 并发 + 归档规下发 + 回读漂移，全量断言
```

夹具：`互斥-百分比转名单`、`互斥-名单转百分比`（须服从同一全局策略）、`互斥-下发归档规`、`互斥-试轨版本`。UI 新增「互斥核证」页，分桶规页可原地归档。
