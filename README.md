# 灰度轨

中文名：**灰度轨** · 前缀 `flagrail` · 端口 **6800 / 11800**

## 骨架

**开关版本入轨 → 分桶灰度下发 → 回读确认 → 失效/回滚互证**

皮：功能开关 / 配置灰度控制台。去皮是 **版本入轨 + 分桶下发 + 回读确认 + 命运互证**，不是配置 CRUD、不是 RBAC、不是发版审批闸。

## 名单百分比互斥（已落地）

同一开关键下，百分比规与名单规**不得并行生效**。全局策略键 `名单百分比互斥策略`（站规表）只有一个合法取值：

- `名单归档百分比` —— **乙口径**：名单写入成功 → 同键原百分比规归档失效（`归档因=名单接管`），生效集只留名单规；百分比回写**整拒**（须先 `/api/分桶/归档` 人工归档名单）。
- 甲口径（后写类型冲突整拒、已有百分比生效时名单写入失败）**不提供**；若站规被改成其它值，核证 `valid=false` 且**停写**（失败闭），不让两套口径并行。

核对点：两次写入（百分比 → 名单）后生效集**不含**百分比（乙）；甲则会含。`互斥核证` 的逐键 `口径结局` 直接给出 `甲:含百分比` / `乙:不含百分比`，两口径结局可区分。

硬约束落实：

| 约束 | 实现 |
| --- | --- |
| 分桶写入与下发读规同票 | 下发在写事务内读规并落票，票面烙 `桶类型 / 规世代 / 规更新时` 快照 |
| 半截不得双规生效 | 写规的「归档旧规 + 落新规」在同一 `BEGIN IMMEDIATE` 事务内 |
| 写规与下发并发须失败闭 | 写事务零等待；拿不到写锁立即 409，绝不排队后按旧规落半截 |
| 下发选归档规必须失败 | `/api/下发` 对 `状态=已归档` 返回 409，票不落、版本态不动 |
| 不得只在 UI 藏一种桶类型 | 分桶规页列出归档规（带归档因/归档时）；写入口不做类型白名单隐藏 |

核证与协同：

- `GET /api/互斥核证?开关键=…`（留空=全站）：开关键、生效规列表、归档规、策略标记、`valid`；逐键含 `口径结局`、`票据`（挂着已归档规的票标 `需复核`）。
- `GET /api/分桶规`：生效规在前，归档规随后列出，不隐藏。
- **回读协同**：票面规世代与库中生效规不一致（被归档/被同类型替换）→ 确认回读转「偏差 · 规漂移」。
- **轨贯验**：同键生效互斥族规至多一条、无双类型并行、已下发票不得落在归档规上。

夹具与自动化：

```bash
python3 backend/scripts/核证_名单百分比互斥.py   # 双序写入 + 并发 + 归档规下发 + 回读漂移，全量断言
```

夹具：`互斥-百分比转名单`、`互斥-名单转百分比`（须服从同一全局策略）、`互斥-下发归档规`、`互斥-试轨版本`。UI 新增「互斥核证」页，分桶规页可原地归档。

## 分桶世代戳（已落地 · 口径甲：戳锁现行规）

热更新后再下发不读分桶世代戳，会出现旧下发点到已归档规、或戳半截失败后下发快照仍绑旧世代。本特性把「生效分桶世代戳」接到**写规闸与下发选规闸**。架构二选一，本站只落实并贯彻甲口径，不提供乙工单口径、无工单入口：

> **以戳锁现行规为准——下发只能绑定戳内生效规集合；戳外/归档规一律拒绝，已下发不得绑定旧集合。**
> （乙口径「持换世代工单才可改绑新集合并升戳号」在本站的可区分结局是：工单有无恒为 `false`，无工单一律拒旧集合，没有改绑通道。）

写规闸（同票，禁止规生效成功而世代戳空）：

| 约束 | 实现 |
| --- | --- |
| 规写入成功必须同票落世代戳 | 写规/人工归档的「改分桶规 + 落世代戳」在同一 `BEGIN IMMEDIATE` 事务；落戳失败整票回滚，落戳后同事务回读核对 |
| 戳面四要素 | 开关键、生效规集合哈希（定序 sha256）、世代号（本键严格单调 +1）、戳时；附生效集/归档集明细 |
| 写规与下发抢锁须失败闭 | 复用零等待写事务：拿不到写锁立即 409，不排队、不落半截 |
| 邻开关键戳不串用 | 戳按开关键隔离，选规闸只读本键戳并核对桶归属本键 |

下发选规闸（写事务内 读规+验戳+落票 同票）：

- 本键无现行戳 → 409（**禁止无戳点规，归档规更不可能被无戳点中**）；
- 桶非生效态/不属当前戳内生效集 → 409（**禁止点到归档/戳外规，不靠 UI 隐藏**）；
- 库内生效集重算哈希 ≠ 戳面哈希（错戳/半截）→ 409；
- 已下发票幂等重投：票面戳世代号 ≠ 现行号或桶已归档 → 按旧集合 409，**已下发不得绑旧集合**；
- 成功回执与下发票列表均烙 `戳世代号 / 戳集合哈希 / 戳时`，回执带回世代号与生效集合。

核证与协同：

- `GET /api/核证/分桶世代?键=…`（留空=全站，**基线所无的只读接口**）：逐键给 `世代号 / 生效集合 / 归档集合 / 工单有无 / 集合哈希 / 戳时 / valid / 违规 / 绑旧集票据 / 历史`。
- `GET /api/核证/分桶世代/历史?键=…`：按开关键翻世代号（旧→新），每代带生效集、归档集、工单有无。
- **回读协同**：票面戳世代/哈希与现行戳不一致 → 确认回读转「偏差 · 规漂移」。
- **轨贯验**：有规无戳、错戳、世代号不单调、已下发绑旧集合，全部亮红；票据回滚收口后转绿。
- **页面**：分桶规页按开关键并排展示「生效集（戳内可下发）/ 归档集（戳外·禁点）」并显示戳世代号，可翻世代号；分桶世代核证页并排两集 + 世代历史；下发票页显示戳世代号/哈希。归档规在接口与页面都照常列出，只在闸口拒绝。

夹具与自动化：

```bash
python3 backend/scripts/核证_分桶世代戳.py     # 同票落戳/热更无工单再下发/错戳/邻键/并发/归档升戳/回读漂移，全量断言
python3 backend/scripts/核证_名单百分比互斥.py  # 原互斥基线回归（含世代戳贯验）
```

夹具：`世代-试轨版本`（入轨）、`世代-热更归档`（百分比生效→名单归档）、`世代-无工单再下发`（点归档规 409 不落票 + 点戳内生效规成功带世代号）。热更后无工单点归档规的脚本断言失败（409 且无新已下发）。
